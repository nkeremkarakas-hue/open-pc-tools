# Katkı Rehberi

1. Depoyu fork edin.
2. Özelliğiniz için bir branch açın: `git checkout -b feature/steam-detection`
3. Değişikliğinizi açıklayan bir commit oluşturun.
4. Pull request açın ve işletim sistemi/Node sürümünü belirtin.

Güvenlik sorunlarını public issue yerine repository sahiplerine özel olarak bildirin.
